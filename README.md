# 🚀 Ansh Portfolio

A modern, premium, and interactive developer portfolio built from scratch using **Vanilla JavaScript**, **Vite**, **GSAP**, and **Lenis**.

Inspired by high-end developer portfolios, this project focuses on smooth animations, clean UI, excellent performance, and an engaging user experience while maintaining an original implementation.

---

## ✨ Features (Planned)

- Premium loading screen
- Smooth scrolling with Lenis
- GSAP-powered animations
- Floating glass navigation
- Interactive hero section
- About section
- AI-inspired chat section
- Featured projects showcase
- Experience timeline
- Contact section
- Responsive design
- Performance optimized
- Dark theme

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Vite
- GSAP
- Lenis
- Lucide Icons
